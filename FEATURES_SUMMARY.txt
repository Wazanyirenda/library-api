1. BOOKS MANAGEMENT (7 Endpoints)
   ✓ GET    /api/books                  - List all books
   ✓ GET    /api/books/{id}             - Get book by ID
   ✓ GET    /api/books/{id}/availability - Check availability
   ✓ POST   /api/books                  - Create book
   ✓ PUT    /api/books/{id}             - Update book
   ✓ DELETE /api/books/{id}             - Delete book
   
   Features:
   - ISBN validation (10 or 13 digits)
   - Availability tracking
   - Genre/author filtering
   - Pagination support
   - Unique ISBN constraint

2. MEMBERS MANAGEMENT (7 Endpoints)
   ✓ GET    /api/members                - List all members
   ✓ GET    /api/members/{id}           - Get member by ID
   ✓ GET    /api/members/{id}/history   - Borrowing history
   ✓ GET    /api/members/{id}/borrowings - Active borrowings
   ✓ POST   /api/members                - Create member
   ✓ PUT    /api/members/{id}           - Update member
   ✓ DELETE /api/members/{id}           - Delete member
   
   Features:
   - Email validation & uniqueness
   - Status management (active/inactive/suspended)
   - Phone number validation
   - Borrowing history tracking
   - Active borrowings view

3. BORROWING RECORDS (6 Endpoints)
   ✓ GET    /api/borrowings             - List all borrowings
   ✓ GET    /api/borrowings/overdue     - Get overdue
   ✓ GET    /api/borrowings/{id}        - Get by ID
   ✓ POST   /api/borrowings             - Borrow book
   ✓ PUT    /api/borrowings/{id}/return - Return book
   ✓ PUT    /api/borrowings/{id}/renew  - Renew borrowing
   
   Features:
   - Automatic overdue detection
   - Fine calculation ($0.50/day)
   - Due date validation
   - Status tracking
   - Business rules enforcement

4. ADVANCED SEARCH (1 Endpoint) 🔍
   ✓ GET /api/search/books?q=query
   
   Capabilities:
   - Unified search across 4 fields (title, author, ISBN, genre)
   - Case-insensitive pattern matching
   - Configurable result limits
   - Fast indexed queries
   
   Value Add:
   + Improved user experience
   + Single endpoint for all searches
   + No need to know which field
   + Minimal code (30 lines)
   
   Example:
   curl "http://localhost:8000/api/search/books?q=tolkien"

5. STATISTICS DASHBOARD (2 Endpoints) 📊
   ✓ GET /api/stats/overview
   ✓ GET /api/stats/popular-books
   
   Overview Metrics:
   - Total books, copies, availability
   - Member counts (total & active)
   - Borrowing statistics
   - Overdue tracking
   - Total fines collected
   
   Popular Books:
   - Most borrowed books ranking
   - Borrow count per book
   - Top-N configurable
   
   Value Add:
   + Data-driven decision making
   + Library performance insights
   + Collection management
   + Trend analysis
   + Minimal code (80 lines)
   
   Example:
   curl http://localhost:8000/api/stats/overview
